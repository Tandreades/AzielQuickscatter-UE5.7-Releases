# Aziel QuickScatter for Unreal Engine 5.7

Downloads for the Aziel QuickScatter plugin, Unreal Engine 5.7 version, by [Aziel Arts](https://azielarts.com).
This page holds the packaged plugin only.

## Download

**Latest version:** [AzielQuickscatter_UE5.7.zip](https://github.com/Tandreades/AzielQuickscatter-UE5.7-Releases/releases/latest/download/AzielQuickscatter_UE5.7.zip)

Older versions and the notes for each release are on the [Releases page](https://github.com/Tandreades/AzielQuickscatter-UE5.7-Releases/releases).

## Install

1. Close Unreal Engine.
2. Unzip the download.
3. Copy the `AzielQuickscatter_vXX.XX` folder into your engine's plugin folder, for example
   `C:\Program Files\Epic Games\UE_5.7\Engine\Plugins\Marketplace\`.
   If an older QuickScatter folder is there, delete it first.
4. Start Unreal Engine and enable **Aziel QuickScatter** under **Edit > Plugins** if it isn't already enabled.
